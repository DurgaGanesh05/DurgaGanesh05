# Install the profile README bundle

This bundle is prepared for `https://github.com/DurgaGanesh05/DurgaGanesh05`.

## Files
- `README.md` — profile content and cards
- `assets/ganesh-hero.svg` — burgundy animated hero
- `assets/ganesh-footer.svg` — matching footer
- `.github/workflows/snake.yml` — generates a real contribution snake SVG using GitHub Actions

## Publish it yourself (no automatic push was made)
1. Install GitHub Desktop if needed: https://desktop.github.com/
2. In GitHub Desktop, choose **File → Clone Repository**, select `DurgaGanesh05/DurgaGanesh05`, and clone it locally.
3. Copy the files and folders from this bundle into the cloned repository, preserving the paths exactly. If `README.md` already exists, replace its starter contents with the bundled README.
4. Review the changes. The profile README includes public repository and demo links; do not add private contact details or secrets.
5. Commit with a message such as `Build profile README and animated assets`, then click **Push origin** when you're ready.
6. Open `https://github.com/DurgaGanesh05` and check the rendering.
7. After pushing, open the repository's **Actions** tab and run or inspect **Generate contribution snake**. The snake won't display until this workflow completes and creates the `output` branch.

## Notes
- GitHub may restrict some SVG SMIL animation behavior. Both SVGs have a complete static design even if motion is disabled.
- GitHub README layouts are sanitized and do not run JavaScript or arbitrary CSS.
- Stats are sourced from a third-party card service and may occasionally be rate-limited; remove a card if it fails to load.
- The skills and project descriptions were drafted from available repository documentation. Review them before publishing to ensure they match your current experience.
